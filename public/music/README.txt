PUT YOUR WEDDING SONG HERE
==========================

Save your audio file in this folder as:

  public/music/wedding-song.mp3

(or use any name and update `music.src` in src/data/wedding.js)

- Use .mp3 - it plays on iPhone, Android and every browser.
- Keep it under ~5 MB so it loads quickly on phones.
- Only use music you have the right to use.
- The music starts when a guest taps the envelope; a small button
  in the corner lets them pause it. If the file is missing, the site
  simply stays silent and the button is hidden.
